@serve-tools/client-interaction

Ask the browser, keep the outcome.

Start each operation directly from a user gesture and see completion, abortion, unsupported APIs, and permission failures represented explicitly.

Choose an interaction above.

Core code; element references and local types match the example above.

import {
	openEyeDropper,
	openFiles,
	share,
	writeToClipboard,
} from "@serve-tools/client-interaction";

copyButton.onclick = async () => {
	const result = await writeToClipboard({
		"text/plain": "Copied text",
	});
	output.value = `Clipboard: ${result.status}`;
};

shareButton.onclick = async () => {
	const result = await share({ title: document.title, url: location.href });
	output.value = `Share: ${result.status}`;
};

filesButton.onclick = async () => {
	const result = await openFiles({ multiple: true });
	output.value = `Files: ${result.status}`;
};

colorButton.onclick = async () => {
	const result = await openEyeDropper();
	output.value = `EyeDropper: ${result.status}`;
};
