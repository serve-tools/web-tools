# @serve-tools/client-interaction demo

A private Vite application demonstrating clipboard, sharing, file-selection, and eyedropper outcomes.

[Open the hosted demo](https://serve-tools.github.io/web-tools/client/interaction/)

From the repository root, run:

```shell
npm run dev --workspace @serve-tools/client-interaction-demo
```

Build and type-check the demo with:

```shell
npm run build --workspace @serve-tools/client-interaction-demo
```
