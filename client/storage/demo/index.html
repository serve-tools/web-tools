@serve-tools/client-storage

Typed browser storage you can observe

Change a persistent local value and a tab-scoped session value. Mutations appear below as precise change records.

localStorage

Color theme

Persists for this origin after the browser closes.

Core code; element references and local types match the example above.

import { Storage } from "@serve-tools/client-storage";

interface DemoStorage { note: string; theme: "light" | "dark" }

const local = new Storage<DemoStorage>();

local.set("theme", "dark");
const theme = local.get("theme");
local.delete("theme");

sessionStorage

Session note

Survives reloads in this tab but not a new browser session.

Core code; element references and local types match the example above.

import { Storage } from "@serve-tools/client-storage";

interface DemoStorage { note: string; theme: "light" | "dark" }

const session = new Storage<DemoStorage>("session");

session.set("note", note.value);
const savedNote = session.get("note");
session.clear();
