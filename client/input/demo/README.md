# @serve-tools/client-input demo

A private Vite application demonstrating pointer geometry and normalized drag-and-drop sessions.

[Open the hosted demo](https://serve-tools.github.io/web-tools/client/input/)

From the repository root, run:

```shell
npm run dev --workspace @serve-tools/client-input-demo
```

Build and type-check the demo with:

```shell
npm run build --workspace @serve-tools/client-input-demo
```
