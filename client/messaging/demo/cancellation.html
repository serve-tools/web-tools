AbortSignal

Cancel remote work

Start a ten-second request, then abort it. The worker receives cancellation through its handler signal.

Ready.

Core code; element references and local types match the example above.

import { client } from "./client.js";

const controller = new AbortController();

const result = client.request("wait", 10_000, {
	signal: controller.signal,
});

cancelButton.onclick = () => controller.abort();
await result;
