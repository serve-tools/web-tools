# @serve-tools/client-shared-db demo

A private Vite application demonstrating SharedWorker-coordinated IndexedDB operations and live committed changes across tabs.

[Open the hosted demo](https://serve-tools.github.io/web-tools/client/shared-db/)

From the repository root, run:

```shell
npm run dev --workspace @serve-tools/client-shared-db-demo
```

Build and type-check the demo with:

```shell
npm run build --workspace @serve-tools/client-shared-db-demo
```
