# @serve-tools/client-keyboard demo

A private Vite application demonstrating platform-relative keyboard chords, labels, symbols, and ARIA shortcuts.

[Open the hosted demo](https://serve-tools.github.io/web-tools/client/keyboard/)

From the repository root, run:

```shell
npm run dev --workspace @serve-tools/client-keyboard-demo
```

Build and type-check the demo with:

```shell
npm run build --workspace @serve-tools/client-keyboard-demo
```
