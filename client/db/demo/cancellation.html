Cancellation

Abort an in-flight scan

The scan reads one committed page at a time. Abort its signal to stop before the next page begins.

Opening the database…

Core code; element references and local types match the example above.

import { database } from "./database.js";

const db = await database;
const controller = new AbortController();
cancelButton.onclick = () => controller.abort();
let count = 0;

for await (const _contact of db.scanValues("contacts", {
	batchSize: 1,
	signal: controller.signal,
})) {
	output.value = `Scanned ${++count} contact(s)…`;
}
