# @serve-tools/client-context demo

A private Vite application demonstrating live context subscriptions as a consumer moves between providers.

[Open the hosted demo](https://serve-tools.github.io/web-tools/client/context/)

From the repository root, run:

```shell
npm run dev --workspace @serve-tools/client-context-demo
```

Build and type-check the demo with:

```shell
npm run build --workspace @serve-tools/client-context-demo
```
