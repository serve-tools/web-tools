# @serve-tools/signal-dom demo

A private Vite application demonstrating reactive functional templates over real browser nodes.

[Open the hosted demo](https://serve-tools.github.io/web-tools/client-signals/dom/).

From the repository root, run:

```shell
npm run dev --workspace @serve-tools/signal-dom-demo
```

Build and type-check the demo with:

```shell
npm run build --workspace @serve-tools/signal-dom-demo
```
