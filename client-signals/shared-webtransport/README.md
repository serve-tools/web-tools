# @serve-tools/signal-shared-webtransport

`@serve-tools/signal-shared-webtransport` observes reliable subscriptions from a worker-owned WebTransport session as explicit Signal state.

```shell
npm install @serve-tools/client-shared-webtransport @serve-tools/signal-shared-webtransport
```

Use the raw shared datagram API for best-effort occurrences.
Dispose each observation before closing its page client; neither action closes the worker-owned physical session for other pages.
