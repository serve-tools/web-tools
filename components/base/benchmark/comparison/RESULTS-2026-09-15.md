# Base / Base UI comparison, September 15, 2026

The Base snapshot measured before the later [whole-package reduction](../reduction/README.md) is smaller than pinned Base UI for Checkbox, Switch, Tabs, Dialog, and their combined entry under the framework-excluded production-bundle metric below.
In the fixed Checkbox JavaScript-completion workloads, the median and p95 intervals across eight paired runs favor Base and clear the predeclared regression bounds.
These results do not establish a whole-library, paint, interaction-to-screen, or assistive-technology advantage.
Tabs and Dialog runtime comparison remains unresolved because the attempted Base UI fixture reached its React commit before its documented transition lifecycle reached final panel and popup visibility.

## Framework-excluded component size

The primary size metric builds minified production ESM with Rolldown 1.2.7 and tree shaking.
The Base bundles externalize generic `BaseElement`, template, Signal, Signal DOM, Signal Effect, and client DOM fragment runtime.
Component-specific foundations such as `FormAssociatedElement`, checked-control behavior, checkbox-group coordination, custom-state handling, and property upgrade remain charged to the component that uses them.
The Base UI bundles externalize React, React DOM, and scheduler while retaining Base UI's component implementation and internal utilities.

The values include each fixture's registration or render usage code and the small external import statements.
They are reproducible scoped application bundles, rather than literal source-only bytes.
Compression is reported independently because compressed-byte subtraction is not additive.

## Checkbox runtime

Ratios are Base UI / Base latency, so values above one favor Base.
The table reports the median of eight fresh-process run medians and two-sided 95% Student-t intervals across paired log ratios.
The fixed no-material-regression boundary is 0.952 for medians and 0.909 for p95.

| Update 100 among 1,000, exact-20 block mean         |         0.0707 |            2.4333 |      34.200, 33.805–34.600 |   33.670, 33.043–34.308 |
| Update all 1,000                                    |         0.7087 |           20.3512 |      28.426, 27.271–29.629 |   27.247, 26.245–28.288 |

Every condition, workload, and pair used a fresh headless Chromium 153.0.8010.12 process.
The eight pairs were counterbalanced independently by workload.
Each condition used its complete production runtime: Base includes its required Base, template, and Signal execution, while Base UI includes React, React DOM, scheduler, and Base UI execution.
No runtime framework cost was subtracted.

The timed mount boundary includes caller setup, construction, connection or React commit, one completion microtask, and a constant-size retained-reference check.
Updates include the public state operation and semantic completion microtask.
Full DOM, form, label, role, state, and accessibility-tree checks run after warmup and recorded blocks, outside the clock.
The grouped update p95 values describe block means, not individual interaction latency.

## Reproduce

Use the pinned dependency closure, then build and preflight after the current Base and dependency distributions are final:

```sh
node components/base/benchmark/comparison/size.mjs \
  --closure-dir /path/to/pinned-closure \
  --output-dir /path/to/output

node components/base/benchmark/comparison/build.mjs \
  --closure-dir /path/to/pinned-closure \
  --output-dir /path/to/output

node components/base/benchmark/comparison/preflight.mjs \
  --build /path/to/output/build-metadata.json \
  --output /path/to/output/checkbox-preflight.json
```

Only run formal timing after confirming that installations, builds, tests, browsers, indexing, and other competing workloads are idle:

```sh
node components/base/benchmark/comparison/run.mjs \
  --confirmed-quiet-slot \
  --build /path/to/output/build-metadata.json \
  --preflight /path/to/output/checkbox-preflight.json \
  --output-dir /path/to/output/checkbox-formal

node components/base/benchmark/comparison/analyze.mjs \
  --input /path/to/output/checkbox-formal/results.json \
  --output /path/to/output/checkbox-analysis.json
```
