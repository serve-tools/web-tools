# Whole-package reduction, September 15, 2026

The pass removes duplicated ownership, reflection, event forwarding, and render work while retaining all public exports and dependencies.
The comparison starts from the already-modified package at the beginning of this reduction request, not Git HEAD; earlier internals, menu, styling, and gallery work is excluded from these savings.

The shared internal DisabledElement removes ten repeated accessors at the cost of 20–30 bytes in several individual entries.
It introduces no constructor, fields, static behavior, or public subpath.

## Runtime

Five counterbalanced pairs used fresh Chromium 153.0.8010.12 processes, with a fresh page/context per workload, on an Apple M5 Max running macOS Darwin 25.6.0 and Node 24.16.0.
The same production bundle fixtures and unchanged lockfile were used for both conditions.
Each workload used five warmup batches and thirty measured batches; the predeclared practical threshold was 5%.
The runner verifies bundle SHA-256 and byte length before launch.

Calendar month updates improved from 52.54 ms to 6.84 ms per batch of 50 updates: **7.68×**, with a 95% paired interval of **7.61–7.75×**.
The p95 comparison was 53.46 ms to 7.08 ms, or 7.55× (interval 7.49–7.61×).
The mechanism is render-local reuse of three Intl formatters instead of constructing fifty, plus fewer redundant writes and renders.
This measures JavaScript/observer completion, not paint or user-perceived interaction latency.

The Field, 100-option Select, and Checkbox/Option create-and-reflect medians changed by approximately −1.2% to +1.0%; none establishes a speedup.
Option construction's median interval was −2.73% to +0.72%; Checkbox construction was noisy at −15.64% to +17.26%.
Construction and several p95 results remain inconclusive; these measurements do not prove general performance equivalence.
The shared base is retained for its aggregate size and policy reduction, not a runtime claim.

One initial run failed the twenty-clock-quanta floor for Field batches of 500.
That run is retained under `rejected-timer-resolution`; both conditions were then measured with batches of 5,000 and a fresh complete five-pair run.
No successful pair was discarded.

## Accepted and rejected changes

Accepted: remove the explicitly unsupported, unused DisposableElement experiment; reuse ScrollArea style ownership; avoid the one-use Field state object while preserving atomic getter reads; remove consecutive duplicate collection checks; consume existing listbox records; reuse Calendar formatters; share disabled reflection; merge native-popover forwarding; share Avatar settlement and Meter/Progress attribute copying.

Rejected: a NavigationMenu snapshot optimization saved 147 bytes but missed synchronous author retargeting during native popup cleanup.
It was restored to the request baseline, and two regression tests retain the evidence.
Tabs keeps its local attribute owner because the shared implementation would increase its standalone entry by approximately 330–430 bytes.
Broad group/selection controllers and lifecycle simplifications remain unchanged because their transaction, reentrancy, and ownership differences make a safe reduction unproven.
