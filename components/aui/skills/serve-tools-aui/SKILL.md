# Use @serve-tools/aui

Treat the installed README and public declarations as the source of truth.
The design inventory is a roadmap, not evidence that a component is implemented.

- For a minimal working element, read [Recipe: quick start](references/recipe-quick-start.md).
- For reactive layouts and connection resources, read [Own the element lifecycle](references/own-the-element-lifecycle.md).
- For native Button, Input, Fieldset, Form, Radio, and Radio Group, or AUI Checkbox, Checkbox Group, Switch, Toggle, Toggle Group, Tabs, and Dialog, read [Compose native controls](references/compose-native-controls.md).
- For Accordion, Collapsible, Avatar, Meter, Progress, and Separator composition, read [Compose disclosures and display elements](references/compose-disclosure-and-display.md).
- For Popover, Tooltip, Preview Card, and Alert Dialog, read [Compose native overlays](references/compose-native-overlays.md).
- For context, drag/drop, and native time entry, read [Use existing platform packages](references/use-existing-packages.md).
- For labels, descriptions, errors, and validation presentation around a native or FACE control, read [Coordinate field state](references/coordinate-field-state.md).
- For native number stepping, one-time-code entry, and single or ordered range inputs, read [Compose numeric controls](references/compose-numeric-controls.md).
- For native autocomplete editing and custom Combobox or Select form values, read [Compose selection controls](references/compose-selection-controls.md).
- For Menu, Context Menu, Menubar, Navigation Menu, and Toolbar composition, read [Compose menus](references/compose-menus.md).
- For Drawer, Toast Region, and Scroll Area composition, read [Compose transient surfaces](references/compose-transient-surfaces.md).
- For an inline Calendar or native File input enhancement, read [Compose calendars and file controls](references/compose-calendars-and-files.md).
