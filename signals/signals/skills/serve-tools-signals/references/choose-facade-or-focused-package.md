# Choose the facade or a focused package

Import the root package when one application module deliberately combines core Signals, native-shaped reactive collections, effects, and asynchronous-operation observation.
Use the focused owning package when only one capability is required and the dependency surface should remain narrow.
Facade subpaths provide focused imports without changing the runtime identity or semantics of the underlying package.
Follow the selected owning package's Skill for behavioral and lifecycle guidance.
