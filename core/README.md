# Core packages

- [`@serve-tools/async-operation`](./async-operation/) provides typed intermediate events, one terminal result, cancellation, backpressure, and asynchronous disposal for owned asynchronous work.
- [`@serve-tools/http-contract`](./http-contract/) defines typed JSON HTTP operations with shared routes, schema-free Fetch clients, validated handlers, and optional OpenAPI projection.
- [`@serve-tools/router`](./router/) provides runtime-neutral typed route declarations, URL matching, and reusable codecs for pathname and search values.
