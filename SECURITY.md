# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Until private
vulnerability reporting is enabled for
[`serve-tools/web-tools`](https://github.com/serve-tools/web-tools), contact the
maintainer privately through the contact information on
[Jonathan Neal's GitHub profile](https://github.com/jonathantneal) before
sharing reproduction details.

Reports should identify the affected package and version, impact, reproduction
steps, and any known mitigation. Receipt will be acknowledged within three
business days, and disclosure timing will be coordinated with the reporter.

## Supported versions

Security fixes are made against the latest released version of each affected
package. Consumers of older versions should upgrade.
